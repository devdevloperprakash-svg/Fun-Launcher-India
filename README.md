# Fun Launcher

Fun Launcher is an independent Android project aiming to bring Minecraft: Java Edition to Android devices with a modern, customizable gaming experience.

> Project Status: Under Development. Some features are planned and may not yet be implemented or fully functional.

## About

Fun Launcher aims to provide a powerful Minecraft Java launcher experience with a premium gaming interface featuring black backgrounds, neon red accents, and neon green indicators.

The goal is to make Minecraft Java Edition easier to manage and play on Android devices.

## Features

- Minecraft Java Edition launcher
- Minecraft version management
- Multiple instance management
- Mod Manager
- Modrinth Store integration
- Fabric and Forge support where supported by the engine
- Java Runtime Manager
- Performance optimization settings
- Graphics and renderer settings
- Resource Pack Manager
- Shader Manager
- Account Manager
- World Manager
- Download Manager
- Launch diagnostics and error reporting
- Black screen troubleshooting
- Modern gaming interface

Note: Features depend on successful implementation and upstream engine compatibility.

## UI Design

- Deep black background
- Neon red primary theme
- Neon green status indicators
- Modern gaming dashboard
- Smooth animations
- Responsive Android interface
- Premium gaming experience

## Platform

- Android
- Designed for Android smartphones
- Targeting devices with 6 GB RAM, including MediaTek-powered devices

Actual performance depends on device hardware, Android version, Minecraft version, renderer, Java runtime, and installed mods.

## Upstream Projects

Fun Launcher intends to integrate the Amethyst Android launcher engine.

- Amethyst Android: https://github.com/AngelAuraMC/Amethyst-Android
- PojavLauncher: https://github.com/PojavLauncherTeam/PojavLauncher

These projects provide upstream launcher technology and retain their respective copyrights and licenses.

## Modrinth Integration

Fun Launcher plans to use the public Modrinth API for:

- Searching Minecraft mods
- Viewing project information
- Finding compatible versions
- Downloading supported mods
- Checking Minecraft versions and mod loaders

CurseForge integration is intentionally excluded.

## Building

1. Download or clone the repository.
2. Open the project in Android Studio.
3. Install the required Android SDK and JDK.
4. Allow Gradle synchronization to finish.
5. Build the debug APK.
6. Test the application on an Android device.

For Amethyst engine integration, follow the official upstream build instructions and preserve required submodules and dependencies.
